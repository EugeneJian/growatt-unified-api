设备数据 / Device Info

Device Info

Device 对象代表一台已授权给你应用的 Growatt 能源设备（逆变器、电池或数据采集器）。设备是 Growatt Open API 的核心资源。

对象属性

核心标识

属性 类型 约束 描述
deviceSn string required 设备唯一序列号（SN）
示例: "DEVICE_SN_1"
deviceTypeName string required 设备大类型名称
示例: "min"
Possible enum values
min max spa sph tlx
model string required 设备型号标识
示例: "BDCBAT"
dtc integer required 设备类型数字编码
示例: 5100
authFlag boolean required 当前 token 是否已授权该设备
示例: true

硬件与固件

属性 类型 约束 描述
nominalPower integer required 逆变器额定功率，单位 W
示例: 6000
communicationVersion string nullable 固件通讯版本
示例: "ZABA-0021"
unifiedAPIver string nullable 统一 API 版本；设备未上报时为 null
datalogSn string required 数据采集器序列号
示例: "DATALOG_SN_1"

电池配置

属性 类型 约束 描述
existBattery boolean required 设备是否配置电池
示例: true
batterySn string nullable 电池序列号；无电池时为 null
batteryCapacity integer nullable 电池额定容量，单位 Wh
示例: 5000
dischargeCutOffSOC integer nullable 电池放电截止 SOC（百分比）
示例: 20

获取设备信息

获取单台设备的完整信息。仅返回当前 token 已授权的设备；未授权设备返回 DEVICE_SN_DOES_NOT_HAVE_PERMISSION。

POST /oauth2/getDeviceInfo

请求参数

参数 位置 类型 约束 描述
Authorization header string required Bearer access token
deviceSn body string required 设备唯一序列号

返回说明

成功时返回 code=0 及完整 Device 对象。失败时返回对应错误码。

错误码

code message 场景 处理建议
0 SUCCESSFUL_OPERATION 查询成功 正常处理 data
2 TOKEN_IS_INVALID access token 无效或过期 刷新 token 后重试
12 DEVICE_SN_DOES_NOT_HAVE_PERMISSION 设备未授权给当前 token 检查设备授权列表
