# Growatt Open API 对外文档客户化审计记录

审计日期：2026-07-22

审计目标：逐份检查中文、英文公开文档，删除仅用于内部联调、测试或编辑协作的内容；从 API 客户视角重写说明；保持已发布接口契约不变。

## 1. 审计范围与事实基线

本次审计覆盖网站 `/growatt-openapi` 实际加载的公开资料：

- `Growatt API/OPENAPI/*.md` 与 `Growatt API/OPENAPI.zh-CN/*.md`
- 中英文 Professional Integration Guide
- 中英文客户版本说明
- 附录 A Growatt Codes 的公开渲染内容
- 文档站页面标题、副标题和导航标签

接口事实以已批准的 `docs/3 接口列表20260424.md` 为规范基线。历史资料、联调报告和测试记录仅用于核验，不作为客户文档，也未被删除或改写为新的接口规则。

不在公开加载范围内的资料包括 `Growatt API/Growatt Unified API.md`、`test/` 下的联调记录、`docs/` 下的内部审计资料以及故障码 SSOT 源文件。它们继续保留为内部证据。

## 4. API 兼容性核对

本次修改遵循以下不变量：

1. API 路径、HTTP 方法和生产区域基地址不变。
2. 请求字段名、响应字段名、已发布枚举和值不变。
3. `redirect_uri` 等必填性以批准的接口基线为准，不采用单次测试中的宽松行为覆盖规范。
4. `client_secret`、token、授权码和设备标识的示例仅做脱敏或占位符替换。
5. 对可选字段、grant 相关字段和不同 `setType` 返回形状的说明属于解析兼容性增强，不要求客户改变有效请求。
6. 产品兼容性采用“按设备、固件和能力确认”的方式；附录 D 可保留受控的 TBD 评审项，但不得把它们解释为型号支持承诺。

## 5. 自动防回归规则

公开文档检查新增以下阻断类别：内部测试路径、内部登录路由、测试域名、真实联调设备标识、实测观察标题、未受控的 TBD/Pending/待确认、内部验收代码、来源冲突措辞和图表生成指令。

这些规则只扫描对外 OPENAPI 页面和中英文集成指南，不会删除内部审计资料，也不会把历史测试记录误当成公开规范。附录 D 仅在同时具备“受控评审稿”状态和客户非支持免责声明时允许保留 TBD。

## 7. 审计结论

公开文档中的内部测试证据、真实联调数据、编辑过程信息和内部验收门槛已从客户视图移除。附录 D 的未确认支持清单按评审需要保留，并通过受控状态、稳定编号、决策表和客户免责声明与正式支持承诺隔离。中英文内容按客户接入任务重新组织，已发布 API 契约保持不变。文档专项检查、生产页面编译、静态导出和协议校验均已通过；仓库标准构建的剩余阻塞来自本次未修改的 Mermaid 测试类型定义，应作为独立工程问题处理。
