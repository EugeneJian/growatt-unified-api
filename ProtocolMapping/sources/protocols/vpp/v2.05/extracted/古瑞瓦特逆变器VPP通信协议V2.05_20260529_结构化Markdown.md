## 0x03 VPP 协议参数

- Profile ID: `fc03_vpp_protocol_params_30000_32099`
- 地址范围: `30000~32099`
- 结构化行数: `117`
- 适用性结论: 0x03 地址 30000 动态返回设备机型 DTC，用于识别设备属于哪一种机型；返回的 DTC 必须存在于当前支持 DTC SSOT。

### 适用 DTC / 机型依据

- 判断方法: 流程：读 30000 → 在 DTC SSOT 匹配 code → 按匹配到的机型类型解释 VPP 寄存器。
- 若单个寄存器备注写明 DTC 限制，以该行备注为准；下方 DTC code 即当前支持清单。
