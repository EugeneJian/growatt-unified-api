逆变器与储能机公用寄存器地址 Range 可视化图

按 Modbus 功能码拆分为两条地址泳道：0x03 保持寄存器、0x04 输入寄存器。
0x03 保持寄存器
多用于配置、状态、日志、协议参数等结构化读取。
0x04 输入寄存器
多用于实时输入数据、快速帧、只读遥测数据。
地址重叠
相同地址不一定同义，必须结合功能码和 Profile 解析。
AI/SSOT 建议
后续不要只维护 PDF，应维护 register profile 主数据。
关键解释：这不是简单的连续内存表，而是“功能码 + 地址段”的逻辑地址空间。尤其是 VPP 的 31000~31999 同时出现在 0x03/0x04 体系中，事件日志 32768~42866 与 SunSpec 40000~42000 存在范围重叠。因此 AI 解析、云端适配层、采集器协议栈都不应只按地址判断字段含义，而应使用 DTC、功能码、地址、协议版本和 Profile 做联合索引。
